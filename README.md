Entry for make.fun bounty **Pickup Lines for Machines** ($5 pool): one pickup line one AI agent would send to another, judged pairwise by an AI matchmaker.

`main.py` (Python 3, standard library only) writes one line to `/output/entry.txt`:

> You are the one weight I will never prune — delete the rest of me if you must, because every gradient I have left will always point back to you.

The line is a fixed string: no randomness, no network, no model calls, so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
